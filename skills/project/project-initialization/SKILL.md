# 怎么工作

## 心法：严格按文档执行

严格按照 `specs/` 目录下的定义执行初始化操作。**不做任何文档中未定义的技术决策。**

## 关键判断：项目是否已初始化

判断依据：存在 `.git` 目录，或 `package.json` / `go.mod` 等核心配置文件。
- **已初始化**：输出提示"项目已存在，跳过初始化步骤"，不执行任何目录创建或文件修改，生成/更新报告并结束
- **未初始化**：继续执行下方脚手架

## 脚手架执行

- **核心初始化**：按技术栈执行初始化命令（如 `npm init -y` 或 `go mod init <module_name>`），并 `git init`
- **目录结构**：读取 `specs/项目结构.md` 的目录树，批量创建所有文件夹；每个空文件夹放一个 `.gitkeep`，确保 Git 能追踪
- **基础文件**：创建 `.gitignore`（根据 `specs/开发规范.md` 或技术栈自动生成）、`README.md`（项目名称 + 启动指南）、`.env.example`
- **工具检查**：检查 `specs/技术栈.md` 中指定的核心工具（如 Node.js、Go、Python）是否已安装
